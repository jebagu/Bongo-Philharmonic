# Bongo Philharmonic — local Mario assets

This is this project's own copy of the first original Mario Paint sprite/model/native-note pack. Keep original pixels, models and prepared-note envelopes. Runtime adapters are in `foundation/src/asset-packs/mario-paint/`. Read README.md for the original source/provenance and tuning exceptions; its old Planet URLs/tool paths are historical. No input ROM is copied here. Assets have no established redistribution license. On 16 October 2026 the user explicitly requested restoration of the fifteen original instruments to the existing public Philharmonic Site; its audited runtime allowlist includes only sprites, GLB models, prepared notes and manifest. All other pack material stays local. Preserve the rights notice; this request does not establish a license. No restore of deleted alternate/upscaled assets is authorized.
