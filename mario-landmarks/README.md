# Bongo Planet — Mario landmarks

Local HTML reference gallery requested on 16 October 2026 for a Mario Paint alternative to the floating North Pole.

Open **http://127.0.0.1:5417/BongoPlanet/mario-landmarks/** using the root `npm run dev` server (strict port 5417). `index.html` is also self-contained and can be opened directly; its remote previews and viewers need internet access.

Twelve existing Sketchfab models cover three flags, three castles, a mushroom house, a Super Star, Luma, Super Mushroom, Question Block and Warp Pipe. Each has a creator link, the current download flag, exact listing license, triangle count, integration assessment, thumbnail and on-demand 3D viewer. The shortlist is stored under `bongo-planet-mario-landmark-shortlist-v1`, separate from all game saves.

Metadata was checked against the public Sketchfab model API on 16 October 2026. `sources.json` is the compact source record. Downloadable means the listing currently offers a download; no model archive has been fetched, converted, optimized or tested in the game. File formats, mesh separation and final material behavior remain unverified. Castle-turret suggestions require extracting a tower from a complete castle.

Listing license labels describe the upload and do not establish rights to Nintendo designs or ripped assets. Keep this research local. Original-game and Composer files are unchanged.

Browser verification on 16 October 2026: all twelve previews loaded; filters returned 3 flags, 4 castles and 5 icons; the classic flagpole's embedded 3D viewer rendered; a three-model comparison and shortlist persistence across reload worked. The 390-pixel mobile layout had one column and no horizontal overflow. Inline data matches `sources.json`, and the gallery JavaScript passed a syntax check. No game-integration verification is implied.
